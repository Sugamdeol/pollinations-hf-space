# Pollinations BYOP Demo Space

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)


**Pollinations QUEST #17249** - A Hugging Face Space people duplicate to build with Pollinations

## Features
- BYOP Authentication - Users enter their own Pollinations API key
- Text Generation - Chat with 100+ models (GPT, Claude, Gemini, Llama, etc.)
- Image Generation - FLUX, DALL-E, Ideogram, Recraft models
- Audio Generation - OpenAI TTS, ElevenLabs, Microsoft MAI voices
- Balance Check - Real-time Pollen balance display

## Quick Start
1. Get a Pollinations API key at [enter.pollinations.ai/keys](https://enter.pollinations.ai/keys)
2. Enter your key (starts with sk_...) in the Space
3. Generate text, images, and audio!

## Duplicate This Space
Click **Duplicate this Space** (top right) to create your own copy!

## Customization Ideas
- Voice Character - Speech in, expressive speech out with personality
- Comic Generator - One prompt -> full comic page with panels
- Narrated Images - Generate image + audio description
- MCP Server Mode - Let agents call your Space
